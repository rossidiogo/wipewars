Guardar a chave do Google (fica só neste computador)

  1. Abra aistudio.google.com/apikey no seu Chrome (já logado na sua conta Google).
  2. Clique em Create API key. Se pedir um projeto, escolha Create project (ou "Create API key in new project").
  3. Copie a chave (começa com AIza) e cole abaixo.
A chave é salva no arquivo .env deste projeto, que não vai para o GitHub.
